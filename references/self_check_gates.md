# 素材自检闸门（阶段 0 · 交付的前置条件）

> 本文只讲**怎么判合格**：检查项、判据、三态后续。**素材该长什么样** → `references/contract.md`；
> **机器可读格式** → `references/output_format.md`；**怎么跑** → `scripts/check_material.py --help`。

**定位**：闸门不是"事后检查"，是**交付的前置条件**。
交付前逐条过；**任一项 FAIL → 就地改 → 整份清单重跑**（不是只重跑失败那一项），全过才交付。

**两套编号别搞混**：

- 闸门编号 = **1 / 2 / 3 / 4**（本文档用）
- 机器编号 = **A1–A15**（静态契约）+ **B1–B7**（无头真渲染），由 `scripts/check_material.py` 产出

---

## 闸门 1 · 完整性 —— 文件能不能独立跑起来

| # | 检查项 | 机器 | 判据 |
|---|---|---|---|
| 1.1 | 单文件、无本机路径残留 | — | 只有一个 `.html`；无 `file:///C:/Users/...` 这类自用路径 |
| 1.2 | 尺寸声明 | A1 / A2 | 样式表**最前面**有同时声明 `width` + `height` 的规则块；推断出的尺寸 = 期望尺寸 |
| 1.3 | 占位符闭环 | A4 | 每个 `{{名字}}` 都有**同名** `data-slot`，反之亦然 |
| 1.4 | 注入入口 | B1 | `window.__setSlot` 存在；且**不注入时页面也有完整默认画面**（不能白屏） |

**不通过怎么办**：1.2 只写一半 → 工具推断不出视口，页会被按错的尺寸渲染；
1.3 拼错 → 数值永远不变且不报错，必须逐个比对名字。

## 闸门 2 · 格式与规格 —— 契约字段是不是写对了

| # | 检查项 | 机器 | 判据 |
|---|---|---|---|
| 2.1 | 命名唯一 | A8 | 同一 `data-slot` 名不重复；避免重复 `id` |
| 2.2 | 引用有效 | A5 | 每个 `data-from` 指向的槽必须存在；`__setSlot` 的默认值也要有对应槽 |
| 2.3 | 条必备字段 | A6 | `data-kind="bar"` 必须有 `data-from` + `data-max` + `data-box` |
| 2.4 | `data-box` 自洽 | A7 | 4 个整数、矩形在画布内、且与元素**实际 `left/top/width` 对得上** |
| 2.5 | 阈值语义 | — | `data-warn` / `data-danger` 方向正确且 `danger ≥ warn` |
| 2.6 | 单位不重复 | — | 用了 `data-suffix` 就别再放静态单位元素（否则 `63%%`） |
| 2.7 | 定位与坐标 | A9 / A10 | `position:absolute` 必须有 `left/top`（或 `right/bottom`）；坐标一律整数 |
| 2.8 | 相对定位陷阱 | — | `bottom`/`right` 相对**最近的非 static 祖先**算 —— 放进整块画布高的容器而不是自己的小容器，会盖住下方整片内容 |
| 2.9 | 不越界 | A11 | 任何元素的**内容包围盒**都不超出 `{W}×{H}`（长文本 + 偏大的 `left` 最常超） |
| 2.10 | 产物清单齐全自洽 | A13 | `<script id="material-manifest">` 存在、JSON 合法、`schema` / `size` / `background` 正确，且 `slots` 与素材里**每一个** `data-slot` 一一对应、字段（`kind`/`from`/`max`/`warn`/`danger`/`fmt`/`unit`）与素材实际一致 |
| 2.11 | 样式全自控 | A15 | 出现的每个原生控件标签（`button` `input` `select` `textarea` `progress` `meter` `option` `ul` `ol` `dl` `h1`–`h6` `a` `table` `fieldset` `pre` `hr`）**都必须在样式表里显式接管外观**：控件类要 `appearance:none` + `background` + `border` + `font-family`；`option` 要 `background` + `color`；`ul`/`ol` 要 `list-style` + `margin` + `padding`；标题要 `margin` + `font-size` + `font-weight`；`a` 要 `color` + `text-decoration`；`table` 要 `border-collapse`/`margin` + `padding`/`border-spacing`；`fieldset` 要 `margin` + `padding` + `border`；`pre` 要 `margin` + `padding` + `font-family`；`hr` 要 `margin` + `border`。**出现却未接管 → FAIL**（不是 WARN） |
| 2.12 | 在线形态（仅 `--mode online`） | A16–A19 | 页面**自己取数**（有 `fetch`、读 `?__api` 或 8766、有失败兜底）；**可托管**（无 `file://`、无盘符、无 `..` 越界，资源相对或 `https`）；**失败可见**（设了 CSP 缺 `connect-src` → WARN）；**不越权**（`/app/show` `/app/quit`、疑似密钥 → FAIL） |

> A12 = DOCTYPE、A3 = 禁居中 —— 属"一般不会写错、但错了直接跑不起来"的兜底项，机器自动判。

**不通过怎么办**：2.5 / 2.6 / 2.8 机器查不到，靠自查；其余按机器报告就地改。
2.10 别手抄清单 —— 用 `--emit-manifest` 打印、或 `add_manifest.py` 就地回填，然后重跑。

## 闸门 3 · 运行时行为 —— 真渲染一遍是不是"活的"

| # | 检查项 | 机器 | 判据 |
|---|---|---|---|
| 3.1 | 注入健壮 | B2 | 对**每个**槽依次注入 `0 / 50 / 100 / 999` 都不报错；条宽与告警色跟着变，999 不得把条撑出框 |
| 3.2 | 无残留占位符 | B3 | 注入后页面上不得再出现字面的 `{{...}}` |
| 3.3 | 包围盒复核 | B4 | 内容包围盒 ≤ 画布（用默认值量，别用极端值把条撑爆） |
| 3.4 | 不重叠 | B5 | 文字×文字、文字×装饰条都不得重叠。**文字×文字要判严**：10px 两行 `top` 差 < 11px 就算叠上 |
| 3.5 | 字号下限 | B6 | 正文 ≥11px、次要 ≥10px、**中文 ≥11px**（另设"中文 10px 档"告警） |
| 3.6 | 对比度 | B7 | 文字色 vs **它底下真实底色** ≥ 6:1（硬线 4.5:1） |
| 3.7 | 动态面积 | — | 每帧变化 ≤ 画布 10%（机器不判，自己核算） |

**不通过怎么办**：3.1 通常意味着 `__setSlot` 里某条分支对 `999` 越界值处理不当
（记得 `clamp(0,1)`）；3.4 把重叠的元素挪开重排区间（用"区间"核算，不要只验包围盒）；
3.5/3.6 改字号 / 压深颜色。

> **B7 的对比度是怎么算的**：取文字元素**中心点** → `document.elementsFromPoint` 拿该点的
> 绘制栈 → 从 `html/body` 底色起、按 `alpha` **逐层合成**出真实底色 → 算 WCAG 比值。
> 所以它能看到"文字底下究竟是哪一层颜色"，而不是简单按页面底色估。

> **在线形态例外**：页面自己取数，不实现 `window.__setSlot` 是合法的 —— `--mode online` 下，3.1 里的「`__setSlot` 未定义 / 抛错」**降级为 WARN**；3.2–3.6（残留占位符、包围盒、重叠、字号、对比度）照旧按 FAIL 判。

## 闸门 4 · 内容与主题一致性 —— **机器查不了，必须看**

| # | 检查项 | 判据 |
|---|---|---|
| 4.1 | 主题对得上 | 说"电脑性能监控"，画面上就得真的是 CPU / 内存 / 磁盘 / GPU / 网络 / 温度 / 风扇 / 进程 这类指标 —— 不要画成时钟、天气、日历、股票，或一个"看着像仪表盘"的空壳 |
| 4.2 | 数据有来源 | 每个动态槽都对应一个真实指标；不出现"没有数据来源的装饰性数字" |
| 4.3 | 中英混用统一 | 标签"中文 + 英文"双写，大小写风格前后一致 |
| 4.4 | 多样性与分布 | 按需求自查明暗分布；多套之间**风格 / 排版 / 数据内容要真的不同**，不能一个模子只换配色 |
| 4.5 | 信息层级 | 主数值与次要指标不要做成一样大；装饰不能盖过数据 |

**不通过怎么办**：闸门 4 没有机器兜底，改完必须**重新逐条对着画面核一遍**上面的判据。

### 谁来看：模型有视觉就自己看

| 情况 | 做法 |
|---|---|
| 模型**能读图**（支持视觉输入） | **必须**自己截图、自己看、自己改：`python scripts/screenshot.py a.html --scale 2` → 读 `out/a.png` → 按 4.1–4.5 逐条判 |
| 模型**不能读图** | **明说"闸门 4 未判"**，把 4.1–4.5 清单 + 截图路径交给人；**不要**假装看过 |

```bash
python scripts/screenshot.py a.html                 # 320x240 → out/a.png
python scripts/screenshot.py a.html --size 320x170  # V1P
python scripts/screenshot.py a.html --scale 2       # 2 倍图，小字更清楚
python scripts/screenshot.py --all --out shots      # 全量出一遍
python scripts/screenshot.py a.html --param cpu_load=57   # 模拟某个数值
python scripts/screenshot.py --url https://x/p.html       # 在线页面
```

注意三点：

- 截图**不注入数据**（与闸门一致）→ 看到的是默认值；要看极端值就 `--param`（`999` 最容易暴露越界）。
- 截图是**自检手段，不是交付物** —— 本技能仍不产出"给别人看的预览图"。
- 看的时候**按 4.1–4.5 一条条说**，不要只说"看着还行"；看不出问题也要写"逐条核对无问题"。

## 怎么跑

```bash
python scripts/check_material.py --all                 # 全部（推荐）
python scripts/check_material.py your.html             # 单个
python scripts/check_material.py your.html --no-render # 只静态（更快，不启浏览器）
python scripts/check_material.py --all --json          # 机器可读报告（下游程序抓这个）
python scripts/check_material.py page.html --mode online # 在线素材（多查 A16–A19，B 层降级）
```

> 机器能查的是**坐标级**问题（重叠 / 越界 / 对比度 / 字号 / 清单自洽）；
> 查不到的是**"坐标都对但看着还是别扭"**（如某个角标位置很莫名其妙）—— 那一类只能靠人眼。
> **注意**：本技能**不做预览 / 截图 / 渲染出图**，闸门 4 的"看图"用你已有的预览手段完成，
> 本技能只负责给出"该看什么"的清单。
>
> ⚠️ **B 层跑不起来**：如果 `B0` 报 `Errno 13` / `WinError 5`（临时目录写不了）或浏览器
> `platform_channel ... 拒绝访问`，说明当前会话是受限令牌 / 沙箱 / EDR 拦截，与素材无关 ——
> 换普通桌面会话运行；只想快速验契约就加 `--no-render` 只跑 A 层。详见 `maintenance.md` §7。

## 三态判定与后续处理

| 判定 | 条件 | 后续动作 |
|---|---|---|
| **PASS** | 全部硬性项通过 | 允许进入下发 / 制作环节 |
| **WARN** | 只命中建议项（10px 中文、对比度 4.5~6:1 等） | **可交付，但必须记录在案**、下一轮统一处理；**不允许当成 PASS 吞掉** |
| **FAIL** | 命中任一硬性项（契约缺失 / 注入抛错 / 越界 / 重叠 / 对比度 <4.5:1 / 残留占位符） | 就地修复 → **重跑整份清单**；连续 2 次仍失败就**停下来问人**，不要靠"放宽阈值"让它变绿 |

> **禁止为了让结果变绿而放宽判据。** 判据是踩过坑之后定的，放宽等于把坑埋回去。
