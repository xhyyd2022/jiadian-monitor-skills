# 风格与排版目录（16 种，全部过闸门）

> 本文只讲**选什么风格、怎么落地**。**形态契约** → `references/contract.md`；
> **判据** → `references/self_check_gates.md`。

做素材库时，**多套之间风格 / 排版 / 数据内容要真的不同**，不能一个模子只换配色。
下面 16 种是实践验证过"确实互不重复"的组合，对应 `assets/verified_materials/` 里的 16 套文件
（1–13 是硬件指标面板，14–16 是外设电量专项）。

> 主产品 v0.9.1 内置 **18 套主题**：其中 16 套与本目录同源；另外两套只在项目里 ——
> 「**本地图片底图**」（演示 ⓑ 本地文件底图，HTML 与 `bg.png` 同层，参考
> `bin/assets/本地图片底图/v2/index.html`；本库要求单文件 + 纯 CSS 底图，故未收）与
> 「**紫绿初号机监控台**」（只有 v2 变体，320×240；当前 B 层闸门会判条/轨道重叠与 1 处对比度
> 5.1:1，故未收进「已验证」库，仅作项目内置主题）。

**通用配色纪律**（比风格本身更重要）：

1. **文字对比度 ≥6:1，判据是它底下的真实底色** —— 不是"深底/浅底"二分。
2. **浅色底平均亮度压在 67~76%**（实测安全区），纯白会拖垮供电/链路。
3. **亮饱和色（招牌红 / 霓虹色）基本都不能直接当文字色** —— 先算对比度，不够就压深或提亮，
   或者让亮色只做**规则线 / 色块**这类非文字元素。
4. 中文 ≥11px、正文 ≥11px、次要 ≥10px。
5. 交付前**每套都要带产物清单块**（`assets/verified_materials/` 里 16 套都已带）。

## 第三批：外设电量专项（14–16，数据来自 `/peripherals`）

三套都只画 `mouse1_*` / `kbd1_*` / `peri_count`，标题栏带 `test-only`，是**外设电量的固定回归样本**。
共同取舍：**只有两行 ×（型号 + 状态 + 大百分比 + 细条）**，因为电量数据 3 秒才更新一次，
画面必须靠排版而不是动效撑住；`_pct` 可能是 `—`（未支持 / 离线），所以百分比字位必须预留
`—` 的宽度（用 `text-align:right` + 固定 `width`，不要让 `—` 把整行推歪）。

| # | 风格 | 明暗 | 排版 | 落地要点 |
|---|---|---|---|---|
| 14 | **键鼠电量深色** | 深 | 标题条 + 两张横条卡 | 每卡两行：`型号 + 状态` 一行、`大百分比` 一行、底部 6px 进度条。条从 `data-from` 继承 `_pct`，`—` 时条宽 0 但不显示 0%。深蓝紫底 + 紫色条 |
| 15 | **键鼠电量浅色** | 浅 | 白底 + 细分割线 + 右对齐大数字 | 与 14 同信息量但改用「表格式」：型号左、百分比右靠边对齐，中间一条浅灰细线。浅色底平均亮度压在 67~76%，纯白会拖垮供电 |
| 16 | **键鼠电量终端** | 深 | 等宽字体 + 方框字符 | `Consolas` + 近黑底 + 亮绿字，标题 `[ DEVICE POWER ]`，卡片用 1px 边框画方框（**不用** `border-radius`），状态文字直接用中文，条用纯色块。终端风最容易做「无圆角、无阴影」的干净重绘 |

> 三套的骨架都刻意保持**最小**：没有动画、没有装饰图形、没有第二个数据源。
> 复制它们去改时，只要替换标题文案与配色就能变成自己的风格；要加环形电量参考 13（圆环）。

## 每帧变化面积（性能杠杆）

唯一性能杠杆 = **每一帧变化的像素面积**，目标 ≤ 画布的 10%。
所以选风格时要顺带想清楚"什么在动"：

- ✅ **便宜**：数字 / 小图标 / 细条 / 状态灯 / 单格变色（几百 px）
- ⚠️ **中等**：整条进度条 / 环形表（1~3 k px）
- ❌ **昂贵**：整屏渐变流动、整屏色相旋转、大面积滚动、整屏转场

**页面自身不带动画、只在数据变化时重绘是完全正确的** ——
抓屏虽按固定节奏轮询，但画面不变时差分结果为空、USB 一字节都不发，这正是省带宽的关键。
不要为了"凑帧率"强加持续动画。
